# Kelime Blokları · Word Blocks

Kelimeleri kaydır, tahtayı temizle!

Komşu harflerden geçerek kelime çiz. Kelime silinir, üstteki harfler aşağı düşer. Bütün harfleri bitir. Takılırsan ipucu doğru sıradaki kelimeyi gösterir ya da tahtayı baştan kurar.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
